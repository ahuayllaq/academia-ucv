# DESIGN.md — AcademIA

## Estilo visual

AcademIA tendrá un estilo limpio, académico y moderno, inspirado en Notion y Linear.

Debe ser una aplicación clara, ordenada y fácil de usar para estudiantes de maestría.

## Colores principales

- Primario: azul universitario `#1F4E79`
- Acento: turquesa `#2EC4B6`
- Prioridad alta: rojo
- Prioridad media: ámbar
- Prioridad baja: verde
- Fondos: blanco y grises claros
- Texto principal: gris oscuro

## Tipografía

Usar una tipografía moderna y legible, preferentemente Inter o Geist.

## Componentes esperados

- Botones
- Tarjetas
- Formularios
- Tabla de tareas
- Modal para detalle de tarea
- Sidebar
- Barra superior
- Badges de prioridad y estado
- Toasts o notificaciones

## Pantallas

### Login

Tarjeta centrada con nombre AcademIA, correo, contraseña y botón de ingreso.

### Registro

Formulario para crear una cuenta nueva.

### Dashboard

Debe mostrar métricas de tareas pendientes, completadas y próximas a vencer.

### Cursos

Pantalla para crear y administrar cursos.

### Tareas

Lista de tareas con filtros por curso, prioridad y estado.

### Detalle de tarea

Modal o formulario para editar título, descripción, prioridad, fecha, estado y curso.

## Reglas visuales

- Diseño responsivo para computadora y celular.
- Bordes redondeados moderados.
- Sombras suaves.
- Espaciado ordenado.
- Colores accesibles.
- La prioridad debe diferenciarse por color, texto e icono.
